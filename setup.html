Create Supabase Account

Free forever. This is where all student accounts and past question data live.

🌐 Create account + project
  1. 1
    Go to supabase.com and click "Start your project"
  2. 2
    Click "Sign Up" and sign up with GitHub (free) or emailIf you don't have GitHub, go to github.com first and create a free account: it takes 2 minutes.
  3. 3
    Once logged in, click "New Project"
  4. 4
    Fill the form:Project name: atu-pq-hub
    Database Password: Create a strong password and WRITE IT DOWN
    Region: West EU (Ireland): closest to Ghana
  5. 5
    Click "Create new project" and wait 1: 2 minutes for it to set up
🔑 Copy your API Keys (VERY IMPORTANT)
  1. 1
    In Supabase, look at the left sidebar and click the ⚙️ gear icon at the very bottom
  2. 2
    Click "API" in the settings menu that opens
  3. 3
    Copy BOTH these values and paste them into a Notepad or Word document:📋 Project URL: looks like: https://abcdefgh.supabase.co
    📋 anon / public key: a very long code starting with eyJ...
🚨
DO NOT copy the "service_role" key! Only copy the anon / public key. The service_role key is dangerous and must never be put in a website file.
✉️ Turn OFF email confirmation (REQUIRED)

Students log in with a Student ID, not a real email. Behind the scenes, the site invents a fake email for each student: which means Supabase can never actually deliver a confirmation link to it. If this setting is left on, every signup will get stuck waiting for an email that will never arrive.

  1. 1
    In Supabase, click "Authentication" in the left sidebar
  2. 2
    Click "Providers" → "Email"
  3. 3
    Turn OFF the toggle called "Confirm email"
  4. 4
    Click "Save" ✅

Connect Supabase to Your Website

Paste your keys into ONE file. This is the only time you touch the code.

📝 You only need to update ONE file

Every page shares the same connection settings through a single file: js/pq-hub.js. Update it once, and every page: login, signup, dashboards, past questions: picks it up automatically.

📋 How to edit the file (step by step)
  1. 1
    Open the js folder inside your website folder, and open pq-hub.js with Notepad (Windows) or TextEdit (Mac)Even better: download VS Code free at code.visualstudio.com: it's much easier
  2. 2
    Find these two lines near the top of the file:
BEFORE (what's already in the file):
const SUPABASE_URL = 'https://psrbdvhszemudyckkbag.supabase.co'; const SUPABASE_ANON_KEY = 'eyJhbGciOiJIUzI1Ni...';
AFTER (replace with YOUR new project's values: keep the quotes!):
const SUPABASE_URL = 'https://abcxyz.supabase.co'; // ← your actual URL const SUPABASE_ANON_KEY = 'eyJhbGciOiJIUzI1Ni...'; // ← your actual key
  1. 3
    Press Ctrl+S to save: that's it, every page is now connected
✅
That's the only code editing you'll ever do! Everything else after this is done through the Supabase website and your admin dashboard: no code.

Create the Database Tables

One script sets up everything: no manual clicking needed.

📋 Run the setup script

Instead of building each table by hand, you'll run one ready-made script that creates all 4 tables, all the security rules, and the file storage bucket: in one click.

  1. 1
    Open supabase-schema.sql (included in your project files) in Notepad or VS Code, and select all + copy
  2. 2
    In Supabase, click "SQL Editor" in the left sidebar
  3. 3
    Click "New query"
  4. 4
    Paste the entire script in, then click "Run" (or press Ctrl+Enter)
  5. 5
    You should see "Success. No rows returned": that means all 4 tables, their security rules, and the storage bucket were created ✅
✅
This one script replaces the old "create a table, add each column by hand" process: and also sets up the file storage bucket, so you can skip straight past manual bucket creation.
📖 What got created
TableWhat it's for
usersStudent profiles: name, Student ID, contact, faculty, level, and an is_admin flag
past_questionsInfo about every uploaded PDF (title, faculty, department, level, year, download count)
downloadsLogs every download a student makes: powers "My Downloads" on their dashboard
pq_requestsPast questions / questions students send to the admin: powers "My Requests" and the admin's "Student Requests" panel
👑 Make Your Admin Account (VERY IMPORTANT)

Nobody starts out as an admin, and nobody can promote themselves from the website. Admin rights can only be given inside your Supabase dashboard. This is what lets Moyole (and only Moyole) into admin.html.

  1. 1
    In Supabase, open Authentication → Users → Add user → Create new user
  2. 2
    Email: the admin's ID in lowercase followed by @students.atupqhub.local, for example admin001@students.atupqhub.local. Type a strong password and switch Auto Confirm User ON. Create the user.
  3. 3
    Open Table Editor → users. A row for that account is already there (it is created automatically). Tick is_admin and save.
  4. 4
    Open yourwebsite/admin.html and sign in with the email and password you just created. That page is the Admin Dashboard. Students never use it: they log in with the Log In button using their Student ID and land on dashboard.html.
  5. 5
    Only the FIRST admin needs the Table Editor tick. After that, sign in at admin.html, create the next admin in Supabase (Authentication → Users → Add user), then open All Students and click Make admin next to them. Use the same button to remove an admin. Open the hamburger menu (top left) for the pop-up, banner, logo, names, contacts and social settings.
🚨
Anyone who is NOT marked is_admin = true is automatically redirected away from the admin dashboard, even if they somehow find the link. Only promote accounts you trust.

Put Your Website Online

Free hosting with Vercel. Your site gets a public URL students can visit.

🚀 Deploy to Vercel (Free): CLI method

Vercel doesn't have a plain drag-and-drop upload like some other hosts: the fastest way for a folder of HTML files with no Git repo is the Vercel CLI, run once from your terminal.

  1. 1
    Install Node.js if you don't have it already: nodejs.org
  2. 2
    Open a terminal (Command Prompt / PowerShell / Terminal) and install the Vercel CLI:
npm i -g vercel
  1. 3
    In the terminal, navigate into your atu-pq-hub folder:
cd path/to/atu-pq-hub
  1. 4
    Run:
vercel
  1. 5
    Log in / sign up when prompted (free, via GitHub, GitLab, or email), then accept the defaults for each question it asks
  2. 6
    It gives you a preview URL like: https://atu-pq-hub-xxxx.vercel.app
  3. 7
    When you're happy with it, make it the live production URL:
vercel --prod
  1. 8
    To get a nicer URL: on vercel.com/dashboard → your project → Settings → Domains → add/edit the project name (e.g. atu-pq-hub)
  2. 9
    Share the link! Done ✅
🔄
To update the site later: Just run vercel --prod again from inside the folder. It redeploys the latest version in under a minute.
🌱 Alternative: deploy via GitHub (no CLI)

If you'd rather not use a terminal, push the atu-pq-hub folder to a new GitHub repository, then on vercel.com/new click "Import Project" and select that repo. Vercel auto-deploys it as a static site: no build settings needed: and redeploys automatically every time you push a change to GitHub.

Solving the Large PDF Problem

PDFs over 5MB are slow to upload and download. Here's exactly what to do.

⚠️
Why large PDFs are a problem: Students on mobile data in Ghana often have slow connections. A 15MB PDF could take 2+ minutes to download. Compressing it to 1MB makes it download in seconds. Also, Supabase's free plan has a 1GB storage limit: compressed PDFs let you store 10x more.
🗜️

Compress It (Best Option)

Go to ilovepdf.com/compress_pdf: free, no sign-up. Upload your PDF, compress it, download. A 15MB PDF often becomes 1: 2MB with no visible quality loss.

📐

Target Size

Aim for under 3MB per past question file. Under 1MB is ideal. Most scanned exam papers should compress to under 2MB.

🔗

Use Google Drive Link

For very large files, upload to Google Drive, make it public, and paste the download link into the file_url field in the Supabase past_questions table directly.

💡
Google Drive download link format:
Get the file ID from the share link: drive.google.com/file/d/FILE_ID/view
Then use this as your download URL: https://drive.google.com/uc?export=download&id=FILE_ID
